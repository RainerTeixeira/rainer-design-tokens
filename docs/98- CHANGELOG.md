# Changelog

## [2.6.0] - 2026-01-04

### 🚀 Features
- **Complete Project Restructuring**: Moved from monolithic structure to modular architecture
- **Token System Enhancement**: Implemented comprehensive primitive and semantic token system
- **Build System**: Added automated build pipeline with multiple format outputs
- **Documentation**: Complete documentation system with 15+ guides and tutorials
- **Testing**: Full test suite implementation with unit and integration tests
- **Storybook**: Component library documentation and interactive examples

### 🔧 Chores
- **File Organization**: Moved CHANGELOG.md from root to docs/98- CHANGELOG.md
- **Token Updates**: Updated tokens.json with latest design system values
- **Package Management**: Migrated to pnpm for better dependency management
- **CI/CD**: GitHub Actions workflows for automated testing and publishing
- **Code Quality**: ESLint, Prettier, and TypeScript configurations

### 📦 Dependencies
- Updated TypeScript to latest stable version
- Added Storybook for component documentation
- Implemented Jest for testing framework
- Added various build tools and development utilities

### 🏗️ Architecture Changes
- **Tokens Structure**:
  - `tokens/primitives/`: Base design tokens (colors, typography, spacing, etc.)
  - `tokens/semantics/`: Semantic tokens derived from primitives
  - `tokens/themes/`: Theme-specific configurations (light, dark)
- **Build Pipeline**:
  - CSS variables generation
  - Tailwind config generation
  - JSON token exports
  - TypeScript definitions
- **Documentation System**:
  - Numbered documentation structure (00-99)
  - Comprehensive guides and tutorials
  - Interactive examples and demos

### 🎨 Design System
- **Color Palette**: Complete color system with semantic roles
- **Typography**: Font scales and line heights
- **Spacing**: Consistent spacing scale
- **Borders**: Border radius and width tokens
- **Breakpoints**: Responsive design breakpoints
- **Animations**: Motion and transition tokens
