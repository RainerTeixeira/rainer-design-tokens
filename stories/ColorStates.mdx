# Color States

Demonstração completa dos estados de cores disponíveis nos design tokens.

## Estados Disponíveis

Cada cor (primary, secondary, accent) possui os seguintes estados:
- **base**: Cor padrão
- **hover**: Cor ao passar o mouse
- **active**: Cor quando ativo/pressionado
- **disabled**: Cor quando desabilitado
- **focus**: Cor quando em foco (acessibilidade)

## Variações

Cada estado possui variações para:
- **background**: Cor de fundo
- **border**: Cor de borda
- **text**: Cor de texto
